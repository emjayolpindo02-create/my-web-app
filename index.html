Examples

Common naming patterns

Ionic compounds

  • NaCl = sodium chloride
  • MgO = magnesium oxide
  • CaBr₂ = calcium bromide

Metal name first, then nonmetal with an “-ide” ending.

Covalent compounds

  • CO₂ = carbon dioxide
  • N₂O₅ = dinitrogen pentoxide
  • SO₃ = sulfur trioxide

Use prefixes: mono-, di-, tri-, tetra-, penta-.

Acids

  • HCl = hydrochloric acid
  • H₂SO₄ = sulfuric acid
  • HNO₃ = nitric acid

Acids often begin with H and are named by their anion.

Hydrates

  • CuSO₄·5H₂O = copper(II) sulfate pentahydrate
  • MgSO₄·7H₂O = magnesium sulfate heptahydrate

Use the hydrate name plus the number of water molecules.
